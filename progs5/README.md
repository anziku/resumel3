# resume_cours

Mes résumés de cours d'élève ingénieur (ENSEEIHT, apprentissage Informatique & Réseaux).

Site : https://anziku.github.io/resume_cours/

## Organisation

Tout est à la racine, un fichier par cours :

```
resume_cours/
├── index.html          ← page d'accueil : la liste des cours
├── README.md
├── methodo-prog.html   ← Méthodologie de la Programmation
└── autre-cours.html    ← chaque nouveau cours
```

## Ajouter un cours

1. Envoyer le résumé à la racine (Add file › Upload files), avec un nom court sans espace ni accent (ex. `archi-ordi.html`).
2. Dans `index.html`, copier le bloc « MODÈLE POUR AJOUTER UN COURS » et remplacer le nom du fichier, la matière, le titre et le résumé.
3. Commit : le site se met à jour en une ou deux minutes.

Mettre à jour un cours : renvoyer un fichier du même nom, il remplace l'ancien sans toucher aux autres.
